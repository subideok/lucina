## 5. 3D 타로카드 구현

CSS만 사용(WebGL 없음). 카드 5장이 `--i`(위치)·`--y`·`--z` 변수로 부채꼴 배치되고, `--lucina-s`(펼침 정도) 하나로 닫힘 → 펼침 → 스크롤 확장을 제어합니다. 두께는 카드 뒤 `translateZ(-1.6px / -3.2px)` 두 겹, 뒷면 패턴은 그라디언트 격자 + 이중 골드 테두리 + 기하 엠블럼(SVG 1개), 빛 반사는 마우스 위치(`--lucina-lx`)를 따라 이동하는 하이라이트입니다. JS가 없으면 카드는 펼친 상태로 정지해 있습니다.

## 6. 상담 전환 설계

모든 CTA는 `data-lucina-consult` 속성 하나로 같은 상담창을 엽니다. 과정 카드는 `data-lucina-course`로 과정을 미리 선택합니다. 상담창에서 관심 과정·경험·희망 방식을 고르면 메시지가 정리되고, "내용 복사하고 이동" 시 클립보드 복사 후 `consultationUrl`을 새 창으로 엽니다. URL이 없으면 링크 대신 설정 안내를 표시합니다. JS 실패 시 모든 CTA는 `#lucina-cta`로 이동합니다.
