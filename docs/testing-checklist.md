## 항목별
- [ ] 텍스트 잘림 없음 (한글 keep-all 줄바꿈 확인)
- [ ] 카드·이미지 겹침 없음 (모바일 히어로: 카피 → CTA → 카드 순)
- [ ] 가로 스크롤 없음 (히어로 overflow:hidden, 갤러리만 가로 스크롤)
- [ ] CTA 높이 56px 이상, 모바일 전체 폭
- [ ] 아임웹 메뉴 정상 작동, 앵커 이동 시 헤더에 가리지 않음
- [ ] 3D 카드가 카피를 가리지 않음
- [ ] 모바일: 마우스 반응 비활성, 부유 애니메이션만 유지
- [ ] prefers-reduced-motion: 모든 애니메이션 정지, 콘텐츠 즉시 표시
- [ ] 이미지 선명도 (권장 크기 이상)
- [ ] FAQ 터치 영역 68px 이상, Enter/Space로 열고 닫힘
- [ ] 상담창: 과정 버튼에서 열면 해당 과정이 미리 선택됨
- [ ] 상담창: Esc 닫기, Tab 포커스 순환, 닫은 뒤 원래 버튼으로 포커스 복귀
- [ ] 상담창: 복사 → 카카오톡/폼에 붙여넣기 실제 확인 (iOS Safari 포함)
- [ ] consultationUrl 비어 있을 때 '설정 필요' 안내 표시
- [ ] 하단 고정 버튼이 아임웹 플로팅 버튼과 겹치지 않음
- [ ] common.js를 빼고 열어도 모든 콘텐츠가 보이고 상담 버튼이 #lucina-cta로 이동
- [ ] common.js를 두 번 넣어도 상담창이 한 번만 열림
- [ ] 폰트 CDN 차단 시 대체 글꼴로 정상 표시
- [ ] Lighthouse 모바일 성능 / 접근성 점수 기록
