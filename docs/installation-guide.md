# 루시나타로 홈페이지 · 아임웹 설치 가이드

> 이 가이드의 메뉴 이름과 위치는 일반적인 아임웹 구조를 기준으로 작성했으며, **실제 관리자 화면에서 검증하지 않았습니다.** 요금제·에디터 버전에 따라 메뉴 이름이 다르거나 코드 삽입 기능이 제한될 수 있으니 설치 전 확인하세요.

## 0. 파일 구성

| 파일 | 넣는 곳 | 수정 빈도 |
|---|---|---|
| `imweb/config.js` | 사이트 공통 코드 (헤더) | **자주** — 상담 링크, 주소, 이미지 주소 |
| `imweb/common.css` | 사이트 공통 코드 (헤더) | 거의 없음 |
| `imweb/common.js` | 사이트 공통 코드 (바디 끝) | 거의 없음 |
| `imweb/sections/01~11.html` | 페이지의 코드 위젯 11개 | 문구 수정 시 |

모든 클래스는 `lucina-` 접두사, 모든 스타일은 `.lucina-root` 안에서만 적용되어 아임웹 헤더·푸터·다른 위젯에 영향을 주지 않도록 설계했습니다.

---

## 1. 공통 코드 넣기 (CSS · 폰트 · 설정 · JS)

**위치(예상):** 관리자 → 환경 설정(또는 사이트 설정) → SEO/고급 설정 → **헤더 코드 / 바디 코드** 입력란.
메뉴가 보이지 않으면 아임웹 고객센터에서 "헤더 코드 삽입" 지원 여부와 요금제 조건을 확인하세요.

### 1-1. 헤더 코드 (위에서부터 순서대로)

```html
<!-- 폰트 (외부 CDN) -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@200;300;400;500;600;700&display=swap">

<!-- 공통 CSS: common.css 전체 내용을 붙여넣기 -->
<style>
  /* 여기에 imweb/common.css 내용 전체 */
</style>

<!-- 설정: config.js 전체 내용을 붙여넣기 -->
<script>
  /* 여기에 imweb/config.js 내용 전체 */
</script>
```

폰트 CDN이 막혀도 시스템 글꼴(애플 SD 고딕 네오 / 맑은 고딕 / 명조)로 대체되어 내용은 그대로 보입니다.

### 1-2. 바디 코드 (페이지 맨 아래)

```html
<script>
  /* 여기에 imweb/common.js 내용 전체 */
</script>
```

> **입력 글자 수 제한이 있는 경우:** CSS·JS를 공개 HTTPS 주소에 올려 링크로 불러오세요. 예) GitHub 저장소에 올린 뒤 jsDelivr 사용
> `<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/계정/저장소@버전/common.css">`
> `<script src="https://cdn.jsdelivr.net/gh/계정/저장소@버전/common.js" defer></script>`
> 로컬 경로(`C:\…`, `./imweb/…`)는 아임웹에서 작동하지 않습니다.

**특정 페이지에만 적용하고 싶다면** 공통 코드 대신, 첫 번째 코드 위젯(01-hero) 맨 위에 CSS·설정을, 마지막 코드 위젯(11-footer) 맨 아래에 JS를 넣는 방법도 있습니다. 코드 위젯에서 `<script>`가 실행되는지는 실제 환경에서 꼭 확인하세요.

## 2. 페이지에 섹션 넣기 (디자인 모드)

1. 관리자 → **디자인 모드** → 홈페이지(메인) 페이지 선택
2. 기존 메인 섹션 중 필요 없는 것은 삭제 또는 숨김
3. **섹션 추가 → 빈 섹션** → 섹션 안에 **코드 위젯(HTML)** 추가
4. 섹션 설정에서 **상하 여백 0, 좌우 여백 0, 가로 폭 '전체(와이드)'**, 배경색 없음으로 설정
5. 코드 위젯에 `sections/01-hero.html` 내용을 그대로 붙여넣기
6. 같은 방법으로 02 → 11까지 **순서대로 섹션 11개** 생성

섹션을 각각 분리했기 때문에 특정 섹션만 숨기거나 순서를 바꾸기 쉽습니다. 단, `10-cta.html`의 `id="lucina-cta"`는 상담 버튼의 대체 이동 위치이므로 삭제하지 마세요.

**아임웹 기본 푸터를 쓰는 경우** 11-footer는 생략하거나, 사업자 정보가 중복되지 않게 한쪽을 정리하세요.

**메뉴 연결:** 아임웹 메뉴 링크에 `#lucina-courses`, `#lucina-instructor`, `#lucina-faq` 등을 입력하면 해당 섹션으로 이동합니다(같은 페이지일 때).

## 3. 상담 링크 바꾸기

`config.js`의 `consultationUrl` 한 곳만 수정합니다.

```js
consultationUrl: 'https://실제-상담-주소',
consultationLabel: '카카오톡 채널',   // 버튼에 "…로 이동"으로 표시
```

- 비워두면 상담 버튼을 눌렀을 때 "상담 링크가 설정되지 않았습니다" 안내가 나오고, 작동하지 않는 가짜 링크는 표시되지 않습니다.
- 상담 버튼(히어로, 각 과정, FAQ, 최종 CTA, 하단 고정 버튼)은 모두 같은 상담창을 엽니다. 상담창에서 **관심 과정 · 타로 경험 · 희망 수업 방식**을 고르면 메시지가 자동으로 정리되어 클립보드에 복사됩니다.
- **카카오톡 채널은 외부 링크로 메시지 내용을 미리 채워 보내는 기능을 기본 제공한다고 확인되지 않았습니다.** 그래서 "복사 → 채널에서 붙여넣기" 방식으로 설계했습니다.
- 아임웹 폼 페이지나 자체 폼을 쓴다면 `passQueryParams: true`로 바꾸면 URL 뒤에 `?course=전문가반&experience=…&classType=…`가 붙습니다. 폼이 이 값을 읽는지는 별도 확인이 필요합니다.
- 연락처(`info.phone`)를 입력하면 상담창에 전화 문의 버튼이 추가됩니다.

## 4. 이미지 바꾸기

1. 이미지를 아임웹(이미지 위젯 업로드 후 주소 복사 등) 또는 외부 CDN에 올려 **https:// 주소**를 확보
2. `config.js`의 `images`에 주소 입력 — 예) `'course-hobby': 'https://…/hobby.webp'`
3. 주소가 비어 있으면 "이미지 교체 영역" 안내가 표시됩니다

| 키 | 위치 | 권장 크기 |
|---|---|---|
| course-hobby / pro / startup / oneday | 04 교육과정 | 1600×1280 |
| learn-main | 05 수업 대표 | 1920×1440 |
| learn-1 ~ learn-5 | 05 갤러리 | 1080×1350 |
| instructor | 06 강사 | 1200×1600 |
| story-1 / story-2, story-3 | 07 수업 기록 | 1600×1600 / 1600×900 |

> 현재 config.js와 06-instructor.html(프로필 `<img src="assets/images/instructor-profile.jpg">`)에는 미리보기용 상대 경로가 들어 있습니다. 아임웹 설치 시 모두 업로드한 이미지의 https:// 주소로 바꿔야 합니다.
> 받은 사진은 가로 160~690px로 작아 큰 화면에서 흐리게 보일 수 있습니다. 원본(가로 1600px 이상)을 받는 것을 권장합니다.

WebP(가능하면) 또는 JPG, 장당 300KB 이하 권장. 이미지는 지연 로딩(lazy)으로 불러옵니다. **AI 생성 이미지를 실제 수업 현장이나 강사 사진처럼 사용하지 마세요.**

## 5. 강사 정보 바꾸기

`sections/06-instructor.html`에서 `[강사 이름 입력]`, `[직함 입력]`, `[확인된 경력 … 입력]`, `[자격명 · 발급기관 입력]`을 실제 내용으로 바꾸고, 바꾼 줄의 `class="lucina-todo"`를 지우세요. 확인되지 않은 경력·자격은 쓰지 않습니다.

## 6. 주소·연락처·사업자 정보

`config.js`의 `info`에 입력하면 푸터에 자동 반영됩니다. 비어 있으면 `[입력 필요]`로 표시됩니다.

## 7. 외부 라이브러리

GSAP·Three.js·Spline은 **사용하지 않았습니다.** 3D 카드는 CSS 3D Transform, 스크롤 연출은 IntersectionObserver로 구현했습니다. 외부 의존은 폰트 CDN 2개뿐이며, 실패해도 콘텐츠와 상담 버튼은 정상 표시됩니다.

## 8. 설치 후 모바일 확인

`docs/testing-checklist.md`의 항목을 실제 휴대폰(iOS Safari, 안드로이드 Chrome)과 아임웹 모바일 미리보기에서 확인하세요. 특히:
- 하단 고정 상담 버튼이 아임웹의 채팅·상단이동 버튼과 겹치지 않는지 (겹치면 `stickyCta: false`)
- 아임웹 모바일 헤더 높이 때문에 히어로 상단이 가려지지 않는지
- 가로 스크롤이 생기지 않는지

## 9. 문제 해결

- **글꼴·여백이 미리보기와 다름:** 아임웹 테마 CSS가 더 강하게 적용된 경우입니다. 개발자 도구로 덮어쓰는 규칙을 확인하고 해당 `.lucina-root …` 규칙에 선택자를 보강하세요.
- **애니메이션이 안 보임:** common.js가 로드되지 않은 상태입니다. 이때도 모든 콘텐츠는 보이도록 설계되어 있습니다.
- **섹션이 화면 폭을 다 채우지 않음:** 섹션 설정의 좌우 여백과 '전체 폭' 옵션을 확인하세요.
