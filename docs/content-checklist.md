# 업체에서 받아야 할 자료

## 필수 (배포 전)
- [ ] 상담 연결 URL (카카오톡 채널 채팅 주소 / 상담폼 / 예약 페이지 중 실제 사용 창구)
- [ ] 정확한 주소 (부산 남구 ○○)
- [ ] 연락처 (공개 가능한 번호)
- [ ] 운영 정보 (예약제 여부, 상담 가능 시간 등 공개 가능한 수준)
- [ ] 상호 · 대표자 · 사업자등록번호 (아임웹 기본 푸터에 이미 있다면 생략)
- [ ] 개인정보처리방침 페이지 (상담폼 사용 시)

## 강사
- [ ] 강사 실명 또는 활동명, 직함
- [ ] 확인 가능한 경력 (기간·기관 포함)
- [ ] 자격증 이름과 **발급 기관** (민간자격이면 등록번호 확인)
- [ ] 강사 프로필 사진 (세로 3:4, 실제 사진)
- [ ] 강사가 직접 말한 교육 철학 한두 문장 (현재는 아카데미 교육 철학 문장으로 대체)

## 교육과정 (사실 확인 필요)
- [ ] 취미반·전문가반이 개인수업/소수정예 중 어떤 방식으로 운영되는지
- [ ] 원데이클래스 분야와 강사 구성, 공지 방식
- [ ] 특강 운영 여부와 공지 채널
- [ ] 수료증/자격 발급 여부 (발급한다면 종류·발급 주체)
- 기간·비용·횟수는 현재 "상담 시 안내"로 표기 — 공개할 경우 제공

## 사진·영상 (실제 촬영본만)
- [ ] 과정별 대표 이미지 4장
- [ ] 수업 현장 대표 사진 또는 15초 내외 영상 1개
- [ ] 수업 갤러리 5장 (리딩 실습, 상징 수업, 질문 분석, 소수정예, 원데이)
- [ ] 수업 기록 3장 (리딩 노트, 실습, 교육 자료)
- [ ] 수강생이 나오는 사진은 **초상 사용 동의** 확보

## 후기 (있을 경우)
- [ ] 게시 동의받은 실제 후기 (수강 전 고민 / 수업 경험 / 달라진 점)
- [ ] 표기 방식 (이니셜, 수강 과정)
- 수강생 수, 만족도, 창업률 등 수치는 근거 자료가 있을 때만 게시
